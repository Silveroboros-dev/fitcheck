# AGI 2028 packaged demonstration

Status: implementation contract for the third fixture scenario.

## User purpose

Explain why a recursive self-improvement announcement is related to autonomous
AI research but does not settle a thesis requiring a public launch or
demonstration by the end of 2028. Compare the same three contract topics as
the retained private run. Preserve an honest no-clean result for this exact
pool.

## Data and authority

The packaged `el/product/demo_fixtures/agi2028.json` is an authored educational
reconstruction. Its English thesis and three project-authored condition
summaries refer to real contract topics. It is neither a provider payload nor
a frozen capture of verbatim resolution rules. No live prices are included.

The resource has a schema version, case ID, content date, thesis, provenance
statement, aggregate result and exactly three ordered market summaries.
Each summary contains a stable local key, authored title, deadline,
conditions, captures, misses, earlier class, current class and explanation.
The RSI current class is `weak_proxy`; the other two are `not_an_expression`.
The aggregate remains `no_clean_expression` in both views.

These are curated explanatory labels. The RSI revision represents a
source-bound relatedness proposal, not a named human semantic adjudication,
golden, new model run or automatically generated proposal for arbitrary
markets. Do not synthesize human decision IDs, acceptance timestamps, source
captures, rule hashes, market-pool IDs or accepted-thesis records.

The exact private historical v1/v2 packet and its original bytes remain
unchanged. Its separate loopback-only route and configured digest checks
continue to work. A public reconstruction must never be labelled "Original
saved run".

## Surface and state

Anonymous fixture mode advertises this case in health metadata and enables a
third menu item, "AGI 2028". The packaged resource also supports the hosted
fixture runtime. Use a fixed, read-only GET endpoint
`/api/demo/agi2028`, returning the case, its canonical SHA-256, and the
current session reference. It performs no inference, provider reads, thesis
acceptance, market selection, correction intake or ledger writes.

Choosing the scenario may use the existing explicit demo-session reset.
All response rendering is bound to the current session and request token.
Changing journeys clears previous cards, case banners and errors. Reset,
reload, missing response, malformed data and late responses must not leave
stale accepted-thesis or market-pool controls visible.

`?demo_history=agi2028` opens the private historical case when explicitly
configured; otherwise it opens this public reconstruction. Public version
controls are "Earlier automatic labels" and "Current relatedness proposal".
The earlier view visibly says "Curated reconstruction" and shows three
`not_an_expression` labels. The current view shows RSI as a `weak_proxy`
proposal. Both views identify the authored condition summaries.

The public renderer uses its own read-only presentation, not accepted-thesis
or market-pool API objects. There are no accept, select, edit or feedback
buttons in this reconstruction. Possible next steps are explanation text,
not nonfunctional controls. Stablecoin and Hormuz remain separate journeys.
